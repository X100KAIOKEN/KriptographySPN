# Java Cryptographic Suite: SPN & Feistel Network

Учебная криптографическая система на языке **Java**, реализующая классические принципы построения блочных шифров: **Substitution-Permutation Network (SPN)** с использованием элементов стандарта ГОСТ Р 34.12-2015 ("Кузнечик"), **Сеть Фейстеля (Feistel Network)**, а также стандартные режимы сцепления (ECB, CBC) с поддержкой динамического **ISO 10126 паддинга** для открытого текста произвольной битовой длины.

---

## Основные возможности

* **SPN-сеть (Substitution-Permutation Network):**
  * 10 раундов шифрования и расшифровки.
  * Использование рамочной таблицы подстановки (S-Box) из ГОСТ Р 34.12-2015 ("Кузнечик").
  * Настраиваемый или дефолтный P-Box (перестановка бит).
* **Сеть Фейстеля:**
  * 10-раундовая симметричная сеть.
  * Раундовая функция: циклический сдвиг влево на 5 бит с XOR-маской (`Integer.rotateLeft(temp, 5) ^ 0x5A5A5A5A`).
  * Полное сохранение симметрии расшифровки через обратный порядок раундовых ключей.
* **Режимы работы блоков:**
  * **ECB (Electronic Codebook)**
  * **CBC (Cipher Block Chaining)** с инициализирующим вектором (IV).
  * **Feistel Block Mode** (обработка всех блоков открытого текста).
* **Динамический ISO 10126 Паддинг:**
  * Поддержка сообщений **произвольной битовой длины** (например, 50, 52 или 144 бита).
  * Автоматическое дополнение случайными байтами и запись длины паддинга в последний байт с последующим точным восстановлением исходной длины.
* **Пошаговая трассировка:**
  * Детальный вывод состояния шифра на каждом раунде (как для шифрования, так и для обратной расшифровки).

## Структура проекта

* `Main.java` — точка входа, консольный интерфейс управления, демонстрация раундов, режимов и проверка восстановления (`true`/`false`).
* `SPNCipher.java` — реализация раундов SPN-сети (S-Box, P-Box, XOR с ключами).
* `ECBMode.java` — режим электронной кодовой книги.
* `CBCMode.java` — режим сцепления блоков шифротекста.
* `ISO10126Padding.java` — механизм паддинга и анпаддинга данных произвольной длины.
* `KeyScheduler.java` — генерация раундовых ключей на основе мастер-ключа.
* `PaddingScheme.java` — интерфейс для схем дополнения.

---

## Принцип работы

1. **Ввод данных:** Пользователь вводит режим работы (`SPN:ECB`, `SPN:CBC`, `SPN:FEISTEL` или `ALL`) и битовую строку открытого текста произвольной длины.
2. **Паддинг:** Модуль `ISO10126Padding` выравнивает данные до кратности 8 байт (64 бита), заполняя недостающие биты псевдослучайными значениями и кодируя длину заполнения в последнем байте.
3. **Шифрование:** 
   * В режимах **ECB/CBC** данные делятся на блоки по 64 бита и обрабатываются SPN-сетью.
   * В режиме **Feistel** блоки проходят 10 раундов сети Фейстеля.
4. **Проверка:** Каждый зашифрованный блок успешно расшифровывается в обратном порядке раундов, паддинг снимается, и результат сверяется с исходным текстом.
